## 本次补齐的材料来源

原版确实包含中高级生物材料来源。之前“没有实际投放”指复刻运行表未接入，不能解释成原客户端没有这些记录。
已复核荣耀版 [npc_catalog.csv](../../starhome_lz_ry_full_parsed/catalogs_utf8/npc_catalog.csv) 的 `produce_obj`：

| 原版怪物 | 原表包含的中高级材料 |
| --- | --- |
| 低温毒胶 | 中级类胶 |
| 恶性毒胶 | 中级类胶、高级类胶 |
| 低温感光质 | 中级能量催化剂 |
| 恶性感光质 | 中级、高级能量催化剂 |
| 毒性奥姆幼虫／毒性奥姆虫 | 中级生物硅；毒性奥姆虫还含中级四足甲的壳 |
| 血腥的奥姆幼虫 | 高级生物硅 |
| 血腥的奥姆虫 | 中级生物硅、中级和高级四足甲的壳 |

这八种中高级材料的所有已登记候选关系均已接入，共 31 种怪物、58 条生物材料规则。
同一怪物同名材料候选合并为一条，数量取原候选的最小至最大范围，避免重复独立掉落造成意外翻倍。
原表 `raw_weight` 算法未确认，**当前每种中级材料独立 75%、高级材料独立 50%**，属于可调整的复刻默认。
保留原候选作为证据，不把它的整数直接当成百分比，也不据此开放其他候选装备或运营道具。

用户另外确认“机器爬虫”和“被遗忘的爬虫（BOSS）”及外观变体掉接合器升级碎片：
每次 **0/1/2/3 个各 25%，期望 1.5**。沿用现有 `DropTable` 的“75% 出 1～3 个”，
未命中时不创建零数量掉落实体；其他机械怪物不增加碎片。
两条碎片规则与生物材料合计 33 种怪物、60 条规则，配置见
[材料掉落表](../data/gameplay/monster_material_drops_v1.json)。
普通机器爬虫当前有 15 张启用地图，例如 `glory_nft_bl_ym_b02`、`glory_nft_bl_ym_b04`、
`glory_nft_bl_ym_d02`、`glory_nft_bl_ym_d04`、`glory_nft_bt_kl_d04`。
BOSS 的掉落定义已配置，但当前刷怪表没有投放该 BOSS，本轮不额外创建 BOSS 刷新点。

新增矿池如下，BL、BT 两个世界均投放，保留原矿池，各新增矿种相对权重为 1：

| 矿物 | 采掘等级 | 地图 |
| --- | ---: | --- |
| 硫矿 | 150 | BL-C07、BT-C07 |
| 磷矿 | 200 | BL-G06、BT-G06 |
| 钾矿 | 250 | BL-H07、BT-H07 |
| 镭矿、铬矿 | 300 | BL-D08、BT-D08 |

镭矿、铬矿的 300 级来自原客户端矿源提示；硫、磷、钾原矿源等级未确认，150/200/250 是本次复刻配置。
矿点位置仍由服务器在可行走区域生成，不声称这些坐标恢复了原服投放。
硫、磷、钾缺独立矿源动画，当前使用各自已经收录的荣耀版矿石图作为地面可点击表现；无跨版本素材导入。
镭矿、铬矿沿用已有荣耀矿源表现。五种矿石都有实际世界视图和采集等级检查。

实现继续经 `CombatDefinitionCatalog → MonsterLifecycle → DropTable` 和现有权威采矿模块结算。
日常任务目录同步识别新增材料来源，可执行佣兵任务由 134 条增至 175 条。
`python -X utf8 tools/build_upgrade_material_supply.py` 可重建投放表并应用矿池配置，重复运行不改变结果；
矿物原版导入工具结束时也会重新应用这组复刻矿池，避免重新导入后丢失。
素材子仓库仅修改 `minerals/mining_asset_manifest.json` 的三个世界表现引用。

本轮验证：`upgrade_material_supply_test.gd` 157 项断言通过；每种爬虫固定种子抽样 40000 次，
0/1/2/3 个次数为 9909/10043/10004/10044，均值 1.5046（理论值1.5）。
五种矿物验证真实生成、低于等级拒绝、达到等级采集、产物 ID 与世界命中；已检查实际渲染截图。
`combat_definition_catalog_test.gd` 2274 项断言通过；总检查集 **38/38 通过**（含脚本零警告），

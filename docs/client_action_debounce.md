# 客户端操作防重复触发

- 接受任务与完成任务共用 300ms 输入间隔，覆盖共用任务窗口中的材料任务及五种训练任务。
- 野外地面拾取独立使用 300ms 间隔，不同掉落物也共用这一拾取间隔；鼠标拾取与智脑自动拾取走同一入口。
- 首次操作立即提交。间隔内的触发直接忽略，不延长间隔、不排队、不在 300ms 后补发请求。恰好达到 300ms 可再次提交。
- 任务回复、按钮文字变化、任务切换及重新打开窗口不重置任务间隔。任务与拾取计时相互独立，不影响购买、出售、移动、攻击、采矿或自维修。
- 采用客户端单调毫秒时钟，不更改 RPC、服务端结算、权威校验或存档策略，也不延迟奖励。
- 任务功能回归按新输入间隔发出有效点击；性能测试在开始采集点击耗时之前等待输入间隔结束，不把等待时间算作命令处理耗时。此前性能样本不作改写。

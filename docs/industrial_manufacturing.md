# 提炼厂与兵工厂生产（2026-09-07）

## 使用入口

提炼厂一层五台提炼设备均可左键点击，二／三层也提供提炼热点。
兵工厂左侧四台设备从上到下为主装备、附属装备、合金、维护包制造。
机器有黄色名称；左键机器 → 开始制作，打开已有非模态生产面板。
悬浮配方查看等级、产量、材料持有量，点击可用配方生产一次。

机器图像继续复用荣耀地图物件，没有导入替代版图片。工业功能分配是复刻配置，
不是从当前地图的 AddImg 推断出的原服处理器。二／三层仍继承既有临时空间复用限制。

输出 `data/gameplay/industrial_recipes_v1.json` 和缺少的材料定义文件。
使用原始产品类解析装备身份，不能按显示名猜测；原表 gun8 的名字错写成虎式突袭，
仍正确解析为虎式加强。运行时只传稳定定义 ID。

- `AssistEquip.txt.decoded`：附属装备制造。
- `AbstractFace`：15 种矿石提炼，10 个矿石产 1 个材料。

  不是缺失数量；旧 `manufacturing_recipes.json` 的这一批记录不能直接执行。

## 权威流程与边界

地图设施 → ManufacturingWindow → 现有玩家面板命令传输 →
AuthoritativeManufacturingService → ManufacturingRecipe → Player.inventory / skills →
既有 autosave commit_player_state → 面板与背包快照。

离线模拟和正式网络模式使用同一服务，不新增客户端扣材料、生成装备或增加经验逻辑。
服务验证权威记录所在地图有该设施、配方属于该设施、背包 revision、技能与材料。
换图后旧窗口不能继续制造。当前权限粒度为同地图，尚未要求玩家走到机器旁。
产物实例使用服务端随机唯一 ID，避免重启导致重复实例身份。
失败事务不提交存档；材料、产物、技能统一通过既有仓储提交路径落盘。

## 明确的复刻规则（不是原服逆向结论）

- 当前单次即时生产，未实现原服处理次数／投入倍率／加工等待时间。
- 除既有烹饪规则外，工业采用等级门槛与达标后100%产出，不臆测原服成功率。
- 原表需求≤10级的工业入门配方允许0级制作，原始要求保留在投影
  `source_required_skill_level`。这是为现有零级生活技能提供成长入口，不改用户存档等级。
- 技能公式对零级取整会得到0，最低经验门槛修正为1；原有正数门槛不变。
- 满级可以继续生产但不再获得技能经验。

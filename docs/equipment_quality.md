# 普通装备品质

2026-09-18：品质作为独立实例事实加入普通装备，不与十星强化、属性加工或五行能量石品质混用。
具备原版 `OnInitEx` 四档品质数组的地面装备才允许非白色品质；旧档、商店购买仍为白色。

原版数值来自荣耀 `cltobj/equipcltclass.fcc`、`appendequipcltclass.fcc`、`fireguncltclass.fcc`。
白/绿/蓝/紫依次对应数组0～3，底盘加生命与输出功率，引擎加推进力，武器加攻击力。
这些是独立固定增量，不占用加工次数，不重复叠到配置基值。比如狙击者战车紫色增加80生命与11输出功率。

合资格装备在制造成功后，使用服务器另一独立随机数抽取品质：白80%、绿15%、蓝4%、紫1%。
**这组概率为复刻拟定**，原客户端没有公开服务端品质分布；可以在
`equipment_quality_rules_v1.json` 调整。现有制造成功率和材料用量不变。
制造详情显示分布，背包与装备名称标记非白色品质，实际属性、换装和战斗模拟使用相同加成。

`EquipmentQuality` 校验实例，`EquipmentQualityRules` 拥有资格/加成/分布；目录工厂拒绝不合资格的品质。
库存、已装装备、客户端投影和战斗条件副本保留独立状态。拆解所需最低绿色品质由此获得正常制造来源。

已登记29款具备原版四档加成的装备，含补回的战斧式/烈火式火箭；两者原图已在素材库，
并补接原版制造配方、弹药、维护、加工和弹体映射，不新增商店在售范围。

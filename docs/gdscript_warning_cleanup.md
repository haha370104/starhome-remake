## 自动检查与报告

在工程目录执行（Godot 可执行文件可替换为本机路径）：

```powershell
& 'C:/Users/tomato/Downloads/Godot_v4.7.2-stable_win64_console.exe' --headless --path . --log-file .godot/check-gdscript-warnings.log --script res://tools/check_gdscript_warnings.gd
```

报告输出到 `.godot/warning-scan-<进程号>/warnings.json`，包括文件、行号、警告代码与说明。
有警告、项目错误、子进程加载失败或超时均返回非零退出码，已接入 `run_project_checks.ps1`。

检查器启动一个仅解析入口的隔离子进程，通过绑定 `127.0.0.1` 的临时调试端口收集诊断。
不会运行游戏场景或读写角色存档，不会改变项目警告设置；只忽略本环境沙箱导致的
Windows 根证书读取错误，不过滤 GDScript 警告。正式入口为 `main_hall.gd` 与
`authoritative_server.gd` 及它们加载的依赖，并非声称未引用脚本和所有未来运行分支都没有警告。

编辑器旧列表可能仍保留上一轮结果；停止运行、清空错误面板后重新运行查看新结果。
这些是加载时静态警告，与另行修复的空地图后台模拟/重复寻路问题分开验收。

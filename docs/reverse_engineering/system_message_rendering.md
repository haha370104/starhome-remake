# 系统提示渲染逆向记录

## 技能升级调用链

荣耀版 `cltplayer/combatclt.fcc` 的 `OnSkillLevelUp(skillname, lvl)` 先把技能标识转换为中文名，再拼接：

`你的` + 技能中文名 + `操作技能提升到` + 等级 + `级！`

随后它调用引擎内建 `_T(...)` 显示这条提示。`_T` 的底层实现不在已经下载的 FCC 脚本中，因此无法从脚本恢复精确的毫秒参数。

## 可确认的表现机制

- `globalfunclt.fcc` 保留了旧系统提示类 `PsText`：黄色文字、14 像素、播放 `sound/buttons.gsm`，新消息会把旧消息向上推。
- 同一类中保留了一条已停用的透明度循环：`loops("alpha", 355, 11, 6, 400, ...)`，证明提示消失由客户端 alpha 动画完成。
- `combat.fcc` 的伤害飘字明确同时使用向上移动 `moveto(0, -800, ...)` 和 alpha 递减。
- 结合原游戏实测，技能升级提示的复刻顺序应为：屏幕中心出现、保持可读、向上移动并逐渐透明、删除。

## 当前复刻参数

- 中央静止：1.5 秒
- 上浮淡出：1.0 秒
- 上浮距离：56 像素
- 颜色：`#fff36b`，2 像素黑色描边
- 多条消息按权威事件到达顺序排队，每条都完整播放

前三项是可调表现参数，不冒充原版精确数值；调用链、文案、颜色倾向、上移/透明度职责均有客户端脚本或实测依据。

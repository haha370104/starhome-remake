## 复刻事务规则

原服成功/失败后的服务端实例变更不可见，以下为本次明确采用的复刻规则：

- 提取成功只移走所选成长，原装备及其他成长保留；失败消耗空白模块，原装备不变。
- 转移要求目标同类成长为空；成功写入成长并销毁模块，失败同样销毁模块及所载成长，目标不变。
- 不截断超上限成长、不覆盖既有成长。孔槽完整搬运晶石、裂纹和绑定，目标不足的基础孔位补为未开孔。
- 选用稳压剂时无论结果都消耗一份。模块继承来源和材料绑定，目标继承模块绑定。
- 原装备、模块和稳压剂由同一库存事务结算；锁定、过期库存版本、装备部署、材料不足、伪造载荷均拒绝。
- 确认框展示成功率与失败后果，确认时固定选择，服务器重新读取真正实例，客户端不能提交成长数值。

模块存档保留类型、来源定义和独立成长载荷，旧档默认为空。背包、持久化和客户端投影均使用同一校验。

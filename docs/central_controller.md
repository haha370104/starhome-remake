# 中枢控制器（P5-D）

本子阶段实施中，不能以规则表和素材导入代表玩法完成。
范围：角色六类桥接芯片、圣焱型核心进化、六件附属装备的0～18阶成长及常驻属性，
有NPC接收证据的炮芯片致命一击。没有改成技能点系统。

## 复刻配置

原版所有常驻生命、攻击、防御除以100。全六类三级芯片合计生命3000、炮攻230、防御240；
核心进化后再加生命2000、炮攻120、防御110，共5000/350/350，与免费版面板比例一致。
芯片未进化时须有对应完好部件；四块护甲、两个发生器均只算一份芯片加成；火箭不能充当导弹，维修/采掘臂不能充当炮。
进化后仍须实际装配武器才能产生该武器攻击，不凭空生成武器。

圣焱原槽33～38与复刻已确认的新式接合器II/发生器II冲突；复刻独立映射为40～45，
不挤占十四格普通装置或晶源体、奥斯格兰、撒玛。六件需核心进化后装配；升级只处理背包中未锁定的装备。
每件18阶额外生命3300、炮攻330、导弹330，数值和材料均在版本化配置中。

致命一击：原概率3%/5%/7%，原伤害为目标当前生命90%。荣耀NPC的
`npcbasecltmain.fcc:337 OnFatalBlow` 有实际扣血接收；这是PVE接入依据，
原服Boss资格与服务器判定次数仍未知。复刻每次有效能量炮射击仅在首个有效碰撞判定一次，
在普通伤害后取剩余生命，额外伤害上限为本次普通伤害5倍，适用于所有怪物。
穿透、发生器、脉冲、核变及致命伤害不会再次触发此判定；死亡仍走统一奖励与任务链。

致命抵抗、电磁干扰尚无现有怪物对应技能依据；制导打击、集中防御、异变打击、核之守护，
以及圣焱附属能力和六档套装技能，保留原用途并明确标记PVP延期，不以普通打怪替代触发条件。

活动供给在P7，本次中枢工坊使用星际币补齐供给：激活模块20000、二级100000、三级250000；
进化晶体500000；六种装备每件100000；六档成长材料5000/10000/20000/40000/80000/160000。
模块是绑定单件物品；进化晶体单件，成长材料原版最大堆叠20。没有额外升级金币收费。

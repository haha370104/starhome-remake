# 素材目录与版本管理

文档校准：2026-09-27。运行时资源统一物化在项目根 `assets/`，所有运行时代码使用 `res://assets/...`。
荣耀版、已取得的免费版和激战版原档保留在项目上级目录，离线中间产物可在临时工作区；规则以[项目全局约定](../PROJECT_CONTEXT.md)为准，
当前全量资源装载范围见[运行内容](../docs/runtime_content.md)。

## 业务分类

| 当前目录 | 业务用途 |
| --- | --- |
| `assets/characters/` | 玩家/非战斗 NPC 裸模、基础动画和共用阴影 |
| `assets/monsters/` | 怪物动作、变体、阴影和调色板 |
| `assets/equipment/`、`assets/equipment_world/` | 服装、战车及其方向动画/叠加层；两个现存入口均须按清单追溯，后续可评审合并 |
| `assets/items/` | 背包、掉落与物品槽视图；不能以统一格子尺寸缩放所有图片 |
| `assets/ui/` | HUD 与交互窗口素材 |
| `assets/maps/` | 底图、小地图、导航、语义遮挡层及摆放清单 |
| `assets/minerals/` | 矿源世界表现 |
| `assets/glory/` | 荣耀版地图、精灵、怪物和矿物包内容 |
| `assets/recovered/` | 跨版本补回的装备、场景和道具素材 |

物品的背包图、面板大图和世界动画是一个业务定义的不同视图，关联规则见
[素材关系](../docs/asset_relationships.md)。地图运行数据单列，不混入穿戴装备。

## 来源与命名

- 非 HUD 素材优先查项目上级目录 `../starhome_lz_ry_full/raw/` 荣耀原档与 `assets/glory/` 现有物化产物；解析缓存可从原档重建，不作为独立来源。
- 原档目录有 `.gdignore`，避免 Godot 生成 `.import` 旁车文件；原档实际字节与索引由 `tools/audit_glory_archive.py` 核对。
- 免费版豁免顶部栏、底部栏/快捷栏、小地图边框，以及用户后续明确批准的任务日志、商城、
  系统菜单和名单边框回退；准确边界见 [免费 HUD](../docs/free_hud_rendering.md)。
  小地图 JPG、人物/背包/战车等未获准窗口及其他非 UI 内容不在豁免中。
- 官网精确路径恢复失败时保留缺口；不使用跨版本、模糊同名或相近图替代。
- 运行路径用业务语义 `snake_case`，动画按实体/变体/动作组织。
  原 `pic/pic2`、时间戳、FCH 哈希、旧窗口类名只保留于 `source_*` 等来源字段。
- 当前全量精灵索引尚有原始目录泄漏，这是待整改问题，不是新的规范例外。

## 物化与版本管理

| 数据 | 策略 |
| --- | --- |
| 源码、JSON 定义/索引、来源审计 | 普通 Git |
| `assets/` 及其中的图片、导航和导入设置 | 本地物化、Git 忽略；由物化清单记录来源 ZIP 校验信息 |
| `.godot/`、日志、临时文件 | 忽略，可重新生成 |
| 工程外原档 | 本地归档，不属于主仓库；不直接纳入运行素材树 |
| 其他恢复中间产物 | 临时工作区保存，可按需重新生成 |

[内容检查](../tools/check_asset_size_policy.py)核对物化清单和本地文件是否齐备；`.import`
边车文件保存可复现导入设置，不能和 `.godot/` 缓存混为一类。

离线生成器使用工程外的荣耀版源档案；运行工程依赖已物化的 `assets/`，不依赖原客户端
安装目录。公开分享仓库或素材前需确认原游戏素材再分发权利。

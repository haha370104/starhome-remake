## 合金制造

| 合金 | 材料 | 制造等级 | 状态 |
| --- | --- | ---: | --- |
| 镍锌合金 | 镍1 + 锌1 | 300 | 保留已有原配方，补齐矿石来源 |
| 锌钛合金 | 锌1 + 钛1 | 400 | 新接入 |
| 钛铬合金 | 钛1 + 铬1 | 400 | 新接入 |
| 钪镁合金 | 钪1 + 镁1 | 550 | 新接入 |
| 钡镁合金 | 钡1 + 镁1 | 600 | 新接入 |
| 锌钡合金 | 锌1 + 钡1 | 600 | 新接入 |

每次产出1份。现有系统没有统一的合金等级计算公式，原配方等级分别配置；
新增配方参照镭铬/镍锌的“原料提炼270级、制造300级”，采用最高原料提炼等级的下一个50级档位：
`(最高原料提炼等级 // 50 + 1) × 50`。这只用于生成新增配方，不改旧配方。
数量、等级与经验为复刻默认，在配方 `source_audit.rule_status` 中注明，不作为原服务器规则。

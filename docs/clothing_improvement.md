# 季节时装改良（P3-C）

2026-09-18：49件原版季节时装、七类仿生纤维、预览/购买/改良/属性生效/保存已接通。
入口为背包右键时装或纤维，以及加工窗口右上「加工项目 → 季节时装改良」。
前缀、特性和1～15级宝石仍按此前用户设计独立运作；原版改良不覆盖其成长。

## 规则证据与复刻约定

- 原版资格与材料阶梯：荣耀 `ven/OterNPC_C.fcc:1809`、`ven/FormClass_ven.fcc:5683,5761`、
  `cltobj/clothcltclass.fcc:7167`；49件继承 `Fashion_2009` 的服装可改良，最高100级。
- 首次成功确定一种方向，此后只能继续相同纤维。材料为 `ven/stuffclt2_ven.fcc:750` 起的七类仿生纤维。
- 当前0～4级每次2份保证成功，5～9级4份，之后每五级翻倍；95～99级为1,048,576份。
  不足时成功率为 `floor(投入数量 × 100 / 保证成功数量)`%。达到100%后不允许多投；
  取整为0%时拒绝操作，避免无意义消耗。这两项拒绝是复刻交互保护。
- 原版纤维每堆9999份，允许跨同类未锁定堆叠扣料；高等级通常不能在当前背包容量内凑齐100%，
  但仍可选择非零概率投入。本次没有私改原版每五级翻倍规律。
- 原版客户端未明确失败后果，采用**消耗所投纤维、保留既有方向和等级**；首次失败不锁定方向。
  未列额外手续费、技能等级或经验奖励，当前只收纤维。使用绑定纤维后时装绑定。

又依赖服务端下发加成，所以这里是采用原版历史数值的复刻规则，不能声称还原了原服服务端算法。
同一注释块中更高改良的三倍暴击、扣除90%生命、无敌等「极品特效」不启用，未证实其PVE范围。

改良固定增量加入人物装备的固定属性汇总，再应用现有百分比前缀与固定代价；
不套用原创宝石“同属性最多两件”的限制。损坏服装不提供改良收益；增加上限不补血、不补能量。

## 获取、素材与兼容

- 加工页出售本角色性别可穿的49件时装子集，每件1万星际币（复刻定价，每次一件）；
  纤维每份20星际币，使用原定义 `m_nWorth=20`，加工页商售渠道是复刻补齐。
- 七张纤维原图在荣耀和激战精确地址缺失，免费版可解析；来源URL与SHA-256同时记录在
  `clothing_improvement_items_v1.json` 与素材子仓库 `items/clothing_improvement/manifest.json`。
  本阶段不替换已有时装图，也不启用未完成维护规则的额外磨损。
- 新增实例字段 `clothing_improvement` 只保存版本、方向和等级；旧档默认0级。
  库存、已穿装备、客户端投影和模拟磨损副本均保留独立状态，加载时验证装备资格。
- 五顶历史误归上衣槽的季节帽，目录按原版帽子归头部。旧档已穿的帽子暂保留原槽，
  卸下或被替换回包后恢复头部槽；不强制占用头部，不丢弃现有头饰。

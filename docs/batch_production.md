# P6 批量生产

日期：2026-09-18。整轮批量库存与经验结算已接入领域；订单、计时、保存与界面仍在实施，尚未交付批量玩法。

## 原客户端证据

- 荣耀 `zyf/maceine/maceineface.fcc:79–148`：各机器共用次数/速度输入窗口。
- `great/code_string.fcc:6581–6583`：界面名称为“运行次数”和“生产速度”；速度范围1～10，
  明确提示提高速度不增加所得经验。不能把速度直接乘到经验上。
- `zyf/maceine/maceinesysclt.fcc:1602–1613`：装备制造校验次数正数、速度1～10，
  然后发送 `r_StartMakeing`；中断也发给服务端。
- `cltplayer/abstractclt.fcc:107–126` 和 `zyf/maceine/maceinefunclt.fcc`：提炼、合金、
  烹饪、裁缝都将次数与 `nMaicHandleStuffRate` 传给服务端。
- `maceineface.fcc:4181–4196`：当前制造未结束时，不能开始另一份制造，必须先终止。
- `maceineface.fcc:496–559`：进度条是循环动画，不能由动画长度推断生产周期；
  声音的10000毫秒循环也不是可靠的生产时间证据。

未确认：原服各设施周期、速度对材料/产量的精确算法、取消当轮的扣料/返还时机。
这些由服务端完成，本次不将客户端RPC函数名当作完整算法。

## 明确的复刻方案

1. 每人一份生产订单，保存配方、设施、开始地图、运行次数、速度、已完成次数和当前轮剩余时间。
   重复轮次按顺序处理，不额外创造多配方并行制造。
2. 次数1～10000，速度1～10。每轮耗材和成功产量均为原配方乘速度；每轮只判定一次原有成功率，
   每轮经验保持原配方经验，再经已有奖励切面处理。装备品质按每件产物独立随机。
   此处耗材/产量解释是复刻选择，原服未从客户端证实。
3. 当前默认每轮2秒，保存在版本化规则中。界面同时显示整份订单所需材料和每轮消耗/产量/经验。
   保留既有烹饪越级概率、工业等级门槛及制造品质规则，不借批量功能重定成功率。
4. 每轮完成时原子结算材料、产物、经验及订单进度；开始等待不提前扣料。
   因而取消未完成轮次无需返还，也不能借取消或重发复制材料。已完成轮次不会撤销。
5. 过程中材料被其他操作用掉、物品锁定或背包容量不足时暂停，保留尚未完成次数；补齐条件后可继续。
   校验失败的轮次不消耗材料、不发经验、不推进完成次数。
6. 切图、断线及重新登录后暂停，已完成成果保留；返回原设施地图后手动继续。
   离线不累计生产。正常退出保存当前等待进度，重启不能重结算已完成轮次。
7. 服务端推进时间，客户端只展示进度；长帧每个角色最多结算一轮，不补跑大量积压轮次制造尖刺。
   普通背包和食品事务不推进订单版本，不让自动保存使取消/继续意图失效。

## 实施和验收拆分

1. 有状态生产订单、批量库存预演、材料/产物/经验原子结算，保留旧配方入口的单轮语义。
2. 可持久化订单、权威命令、运行时等待与暂停，真实服务器重启/断线/切图/写盘失败回归。
3. 数量与速度选择、预览、进度、暂停/继续/取消入口，真实渲染和总门禁。

# 背包自由坐标规则（2026-09-07 确认）

本说明取代旧面板文档中的“矩形不得重叠”“15 像素吸附”和“每次回包自动排格”规则。

- 背包位置仅由物品中心的 `position_px` 决定，界面以该坐标为中心显示，服务端原样保存；允许两个或多个不同物品完全重叠。
- 拖动不自动吸附、不交换物品、不挤开其他物品，不改变物品数量或身份。
- 只有点击「整理背包」才按稳定实例 ID 排列，物品中心坐标对齐到当前网格的五列八行中心；索引 0..39 按网格中心计算。
- 容量仍为 40 件/堆叠，身份唯一性、容器、坐标边界、锁定和 revision 校验继续生效。允许重叠不放宽这些规则。
- 图标继续使用统一的显示尺寸及 5px 内边距，和其自由摆放坐标是两个概念。重叠时后绘制的物品接收鼠标，可以先拖开上面的物品。
- 新拾取、购买或卸下的物品优先放在未被现有图标覆盖的虚拟格子，不重排原有物品；若自由摆放遮住了所有格子但未满 40 件，仍允许选择默认坐标放入并重叠。
- 旧存档 `footprint_px` 暂保留兼容，但不再参与重叠拒绝、布局容量和坐标边界计算，无需删除或重建存档。

## 手势修复

之前每次左键松开都会发移动命令，包括只想单击或双击装备的情况；同时客户端显示顺序格子、服务端保存像素位置，两个坐标体系不同，导致频繁出现 `inventory items overlap`。

真正拖动保持抓取点偏移，只显示鼠标下的完整物品，不保留原位副本或半透明阴影。放回背包或拖入仓库按物品中心自由落位；从背包放到自身附近的可行走地面则整堆丢下，城内与野外均可拾回，实例身份与成长状态保留。当前附近范围为125世界像素；锁定或绑定物品不可丢弃。其他窗口或无效落点取消，服务端拒绝时恢复权威位置。

## 地面摆放与清理

- 玩家主动放下的物品保留精确世界坐标，不吸附、不合堆，支持排列图案。智脑自动拾取跳过玩家摆放的物品，手动拾取不受影响。
- 全服每24小时统一清理全部地面物品，固定在UTC零点，包括玩家摆放、怪物掉落和休眠地图；不是每件物品各存活24小时，也不是累计开机24小时。
- 玩家摆放连同完整实例属性写入服务器存档。背包与地面之间的转移在同一原子文件快照中保存；沿用后台检查点，正常退出须写盘成功。崩溃可能回退到上次检查点，但不会分别保存两端导致复制或丢失。
- 未过清理时点便重启，恢复原有摆放；关服期间跨过清理时点，启动时先清理，不延长存活时间。未访问地图的物品按需恢复，不为存档加载全世界。怪物掉落不持久化。
- 服务器文件根格式升级为4，人物记录格式仍为3。停服后执行 `python3 tools/upgrade_ground_item_save.py <服务器存档路径>`，工具逐字节核对备份及人物内容，再一次性升级；运行时不读取旧根格式。

实现仍通过 `Inventory.move_item()`、`InventoryLayout` 维护充血领域规则与 revision；未增加客户端单独持久化或绕过服务端校验。

# 护甲精工（P3-B）

2026-09-18：已接通材料/基础护甲购买、预览、权威交易、失败销毁、装配和保存。
在背包右键护甲或材料可直接进入；没有材料时，从任意装备的「基础属性加工」窗口，
通过右上「加工项目 → 护甲精工」进入购买。

## 原版明确的部分

- 电激波/电磁波护甲四个部位、第一至第八阶，另含赠品第一阶与已满阶勇士变体，共40个定义。
- 第一至第三阶用精工芯片：投入1～9个成功率为 `30 + (数量-1)²`%，至少10个100%。
- 第四至第七阶用对应前/后/左/右部位精工石：1/2/3/4个成功率10/30/60/100%；不能投入5个以上。
- 失败后装备和消耗材料全部消失；第八阶不能继续精工。
- 对照源码：荣耀 `ven/OterNPC_C.fcc:1373`、`ven/FormClass_ven.fcc:3686`、`great/yl_great.fcc:258`，
  装备定义在 `cltobj/equipcltclass.fcc` 的 `ProcessArmmor*` 及四方向子类。

## 状态与验证

阶级就是装备定义，无重复等级存档。规则由 `ArmorRefinementRules` 验证，
`ArmorRefinement` 生成保留成长的候选，玩家聚合协调材料与完整替换，库存只提交一次版本。
预览不能包含运行时领域对象，网络只发送已转换的数值和文本；锁定、缺料、错部位、过期版本、
已装配、损坏和未确认销毁均无副作用；满背包可以原位换代，不额外占一格。

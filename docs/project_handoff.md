## 4. 关键架构，不能走回头路

- 客户端只发送意图。怪物生成、命中、扣血、能耗、产矿、奖励和持久化均由服务器决定。
- 本地和 ENet 只替换传输；不新增 offline 专用战斗、背包、矿源或经验实现。
- **进程内服务器现在是传输节点的子节点，自动模拟只由服务端 `_physics_process` 推进。**
  传输层不能再在 `_process` 推一次。手动 tick 仅用于暂停自动物理处理的测试。
- 关闭本地连接先断开可达引用、同步保存，最后 `queue_free()`；不要在信号回调里直接 `free()`。
- 客户端 Player 是同身份/同 revision 的快照重建，不与服务端共享内存指针。
  掉落、背包、穿戴的同一物品由实例身份联系；不同渲染模式不等于三份业务数据。
- 移动状态唯一写入者为 LocalPlayerController；ActiveWorldController 原子替换地图 bundle。
- 人体、服装、翅膀整体参与场景排序；图片原点、物体脚点、导航坐标不可混用。
- 主槽旧协议键 `energy_cannon` 只表示兼容输入槽，当前类型读 `VehicleEquipment.primary_device_kind()`。
- 具名 GDScript 函数写中文 `##`，说明作用、`[param ...]`、返回值和特殊抽象/权威设计。
- 每次独立模块提交不超过 20 个文件、增删合计 2000 文本行；显式暂存，资源/业务分批。
